Overview

About the project.

The Order Screen or the "Order Board" is a .NET windows Application, that runs on a large TV in the warehouse.

The goal was to improve the efficiency of the warehouse by providing a real-time order management board that allows employees to view the number of unpacked orders and will update in real-time.

Before the Order Screen, order information was scattered across multiple systems, making it difficult for employees to get a comprehensive view of the warehouse's status. The Order Screen solved this problem by providing a centralized, real-time view of all orders.

Highlights

Interesting parts.

01

APIs

Since orders are scattered across multiple systems, I had to integrate with multiple APIs to get the data I needed. This was a challenge, as some of the APIs were not well documented and required a lot of trial and error to get working.

02

Interface

Since this TV needed to be viewed from a distance, I had to design an interface that was easy to read and understand. I used large fonts and high contrast colors to make the information easy to read from across the room.

03

Real-Time Updates

The Order Screen needed to update in real-time, so I had to implement a system that would push updates to the screen as they happened. I used timers to check for updates every 5 seconds, and if there were any changes, the screen would update automatically without the need for a manual refresh.
