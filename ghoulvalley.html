Year [2023-2024]

Role Primary Developer

Overview

About the project.

Ghoul Valley is an 2D Multiplayer MMORPG that I developed as a personal project. The game is built with C# and Unity, and is hosted on Amazon AWS EC2. The game features a variety of different classes, each with their own unique abilities and playstyles. Players can explore the world, complete quests, and battle against other players in PvP combat.

The game is currently complete/inactive, since I was on a budget and hosting was expensive, the project was discontinued in 2024.

Highlights

Interesting parts.

01

Multiplayer with AWS EC2

The game is hosted on Amazon AWS EC2, which allows for a scalable and reliable multiplayer experience. Players can connect to the server and interact with each other in real-time, creating a dynamic and engaging gameplay experience.

02

Integration with Stripe

At first, this game was going to be a free-to-play game with in-game purchases. I integrated Stripe into the game, which allowed players to purchase in-game items and currency. However, due to the high cost of hosting, the project was discontinued before this feature could be fully implemented.

03

Centralized Management

The game features a centralized management system, which allows the developer to manage the game and its players from a single location. This system allows for easy updates and maintenance, as well as the ability to monitor player activity and behavior.
