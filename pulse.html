Overview

About the project.

Pulse is a integration management application, designed to improve integration processes and locatability.

The goal was simple: create a 1 stop shop for all integration processes, and make it easy to find and manage integrations.

Before Pulse, integrations were hosted all throughout the company, and it was extremely difficult to find and manage them. Pulse solved this problem by providing a single location for all of the integrations, and making it easy to find and manage them.

Webhooks section of Pulse, allowing users to create webhooks and assign an event to create functionality.

Highlights

Interesting parts.

01

Webhook Management

Users are able to create webhooks, which are then assigned to an event, which allows for functionality to be created when that event is triggered. This is extremely useful for users who have no knowledge of programming, so creating event handlers and tasks is made easy wiith minimal effort.

02

Integration Management

Users are able to create integrations (for specific platforms), without any knowledge of coding. This acts as a "plug-and-play" system, where all they need to do is upload the needed credentials.

03

System Management

The system provides a centralized interface for managing all systems and IoT devices within the network, allowing system administrators to view server status, and monitor system health.
